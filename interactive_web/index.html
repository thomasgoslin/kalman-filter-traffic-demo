REICH AND COTTER §6.1 / ALGORITHM 6.3

Model and notation

Each vehicle has its own linear Kalman filter. The forecast propagates its mean and covariance. A matched detector reading turns that forecast into an analysis.

State and observation

Zn= (cx,cy, w,h,vx,vy) T , Yk=Hzref(tk)+Σk

The state Zn contains the box center and size in pixels, plus the center velocity in pixels per frame. The observation operator H selects the first four components. A YOLO box supplies the realized observation yobs(tk) once it is assigned to a track.

The book uses n for model steps and k for observation times. The player uses one source-frame index for both displays. Every frame advances the model by one step, and frames with a matched box supply observations.

Forecast (6.6), (6.10)–(6.11)

z̄n+1=Fz̄n, Pn+1= FPnFT+Qstep

The demo uses F = I + δt D with δt equal to one source frame and b = 0. The transition adds each velocity component to its corresponding center coordinate and carries the size and velocity forward. The model assumes independent zero-mean Gaussian process and observation errors. The matrix Qstep, called Q in the code, is the covariance added at each step. It corresponds to 2δt Q in the book.

Analysis (6.12)–(6.13)

Kk=PkfHT (HPkfHT+R) −1 z̄ka=z̄kf+Kk (yobs(tk)−Hz̄kf) Pka=Pkf−KkHPkf

The gain Kk converts the residual between the observed and predicted box into a state correction. The code evaluates the equivalent Joseph form for Pka. With no matched observation, the forecast is carried forward and there is no analysis at that frame.

For a new track, the first box sets the initial center and size, velocity starts at zero, and the filter assigns covariance P0.

What the plots show

The linear–Gaussian model represents each forecast and analysis by a mean z̄ and covariance P. Each shaded time-series band is the current marginal interval z̄i ± 1.96√Pii. The center ellipse uses the joint covariance of (cx, cy) and encloses 95% of the model’s Gaussian probability at that frame.

The constant-velocity model, IoU-based box matching, and simulated detector errors are choices for this demo. The uncertainty regions describe the assumed model. The footage supplies no ground-truth box centers for testing their coverage.
